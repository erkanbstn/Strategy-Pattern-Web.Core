# Strateji deseni

Ürün kayıtlarını SQL Server veya MongoDB üzerinde strateji deseniyle saklayan web uygulaması.

## Ne var

Ürün, hesap ve ayar controller'ları vardır.

## Çalıştırma

```powershell
dotnet run --project Strategy.Pattern.Core.UI
```

## Yığın

.NET 5, ASP.NET Core MVC, Identity, Entity Framework Core, SQL Server ve MongoDB.
